# 复用轮序视觉，并适配手机与 Pad

状态：已实施并完成自动化验收。日期：2026-09-28。下文保留初始视觉计划；以下追加范围优先于原计划中的组件保留约定。

## 第二轮追加：小屏重梳理（2026-10-01，优先于下文两处旧决策）

实测第一轮的「手机顶部横向导航 + 大表整表横滚」在手机上不可用（调度表 4115px、请求记录筛选条约 1400px）。本轮替代原计划第 43 行（手机横向导航）与第 64 行（表格只横滚不改卡片）两条决策：

- **手机导航改汉堡抽屉**：≤760px 侧栏隐藏，顶栏吸顶（汉堡 + 品牌 + 消息 + 退出），导航收进左侧 `UiDrawer`（宽 `min(300px, 84vw)`），点击后关抽屉跳转。Pad/桌面侧栏不变。
- **手机端表格卡片化**：`UiDataTable` 新增 `card` / `card-collapse` props，`useViewport().phone` 为真时行渲染为卡片（`.table-cards`），列标记 `mobileTitle` / `mobileTag` / `mobileHide` 驱动布局，`fixed: 'right'` 列成为卡片动作行；`card-collapse` 时隐藏列收进「更多字段」折叠区。接入：Upstreams 提供商表（手机逐行渲染提供商，不再 rowSpan 合并）、ApiKeys 两张表、RequestLogs 主表（隐藏 IP/分组/协议等次要列，点卡片开详情）、Scheduler 候选表（6 个核心列 + 更多字段折叠）。Dashboard 小表保持横滚表格。断点跨越只重渲染表格，不销毁页面。
- **筛选收进抽屉**：RequestLogs 七控件筛选条与 Upstreams 筛选网格在手机隐藏，页面留「筛选 · n」（n=已生效条件数）按钮 + 查询/刷新；抽屉内纵向全宽排列，footer 放查询/重置。Upstreams 快捷筛选 chip 组保留在页面。
- **Pad 档流式**：761–1100px 区间固定宽度筛选控件（`.toolbar`/`.explain-bar` 直接子元素）改为 `flex: 1 1 200px` 流式折行。
- **`useViewport()` 启用为唯一断点来源**：删除 UpstreamsView 私有的 `window.innerWidth <= 760` 监听；补 `MenuOutline` / `FilterOutline` / `CloseOutline` 图标；移除已无引用的 naive-ui 依赖。
- **RouteGroupKeyPicker 手机堆叠**：key 行改为换行布局，倍率/余额加伪元素标签，表头行隐藏，去掉 680px 最小宽度（仅手机档）。
- 验证：`visual_regression.py` 新增手机专项（导航抽屉开合跳转、四页 `.table-cards` 无横滚、筛选抽屉填条件查询生效）；picker 列对齐断点移回桌面档；`ui_regression.py` 390 档断言改为卡片容器。

## 追加范围与实现记录

- UI 组件整体采用轮序的原生 HTML/CSS 结构，在 frontend/src/components/ui/ 移植为 Vue 组件；不再使用 Naive UI 展示组件。覆盖按钮、表单、标签、卡片、分段选择、下拉菜单、表格、弹窗、抽屉及消息。参考项目没有的分页、日期范围和复杂筛选，用同套原语承接现有业务。
- 参考项目没有菜单栏折叠交互，因此移除原 Naive 侧栏折叠控件及折叠偏好读取；桌面 224px、Pad 190px、手机横向导航。
- 布局只有一个 router-view，跨 760px 断点不会销毁业务页面。
- 修正登录页盒模型，手机仅保留品牌条与表单；选择器表头和行共享 680px 最小宽度；弹窗通过原生 dialog 的独立滚动内容区和固定 footer 保证按钮可见。
- 原有 ui_regression.py 保留分页、轮询、竞态和明细回归，改用新组件选择器，并按具体 Key 定位同步操作，避免依赖倍率排序后的行位置。
- 新增 visual_regression.py，用隔离接口 fixture 检查 1440/834/390 三档、五个业务页面、登录、草稿跨断点保持、提供商与密钥保存、长表单滚动及选择器对齐。所有写请求均由浏览器 fixture 接收。

## 初始计划（历史记录）

本项目保持 Vue 3 + Naive UI。只改前端外观和布局，不改接口、路由和业务逻辑。产品名仍是「供货商管理」。

## 2. 断点

与轮序同一套宽度，覆盖手机和 Pad：

- **桌面 ≥1101px**：侧栏 224px，可折叠到 64px。现有 `sum-sider-collapsed` 只在这一档生效，避免弄坏 `frontend/tests/ui_regression.py`（1600 宽且预置折叠）。
- **Pad 761–1100px**：侧栏收到 190px，内容边距约 24px。指标 2×2，筛选两列，图表单列或在较宽 Pad 上两列。
- **手机 ≤760px**：侧栏改成顶栏下方可横向滑动的导航，五项都露出文字。不再留 64px 图标栏。内容边距约 16px，指标 2×2，表单标签改到上方，弹层宽度 `min(原宽度, calc(100vw - 24px))`。

新增 `frontend/src/utils/viewport.ts`，用 `matchMedia` 暴露 `phone` / `pad`，布局和少数表单共用。图表已有 `ResizeObserver`，不另改。

## 3. 改哪些文件

1. **`App.vue` 主题**  
   `themeOverrides` 换成上表主色、成功/警告/错误、圆角、卡片和文字色。Naive 的信息色、标签、单选按钮、开关跟着主色走。

2. **`style.css`**  
   页面底、`.page-head`、`.muted`、表格行悬停改成同一套。页标题约 22px、字重 650。手机上 `.page-head` 改为纵向，工具条允许换行。固定宽度的筛选控件在窄屏改为 `width: 100%` 或 `min-width: 0`。

3. **`AdminLayout.vue`**  
   侧栏底色、品牌方标（「供」）、导航选中态、顶栏高度和底栏说明按轮序重画。手机档用横向导航，点选后留在当前页。顶栏标题在手机上缩短，退出按钮保留。

4. **`LoginView.vue`**  
   桌面和 Pad 用左右分栏；手机只留表单，上方放缩小的品牌条。文案保持「使用后端静态 ADMIN_TOKEN 登录」和「进入控制台」。

5. **五个页面的窄屏**  
   - `DashboardView.vue`：960px 一刀切成单列改为 Pad 2×2 指标、经营区上下叠、图表单列；手机指标仍 2×2。期间切换和日期选择允许换行。负毛利用 `#a16d50`。
   - `UpstreamsView.vue`：已有 760 / 1000 断点，颜色和页头间距跟新主题。筛选在手机上两列，查询/重置占满一行。
   - `ApiKeysView.vue`、`RequestLogsView.vue`：工具条和筛选去掉写死宽度，窄屏折行。表格继续横向滚动（列多，不改成卡片）。请求明细抽屉已是 `min(640px, 100vw)`。
   - `SchedulerView.vue`：把现有 640px 表单折行规则提到 760px，并让调度候选表在手机上可横滑。

6. **弹层宽度**  
   `ApiKeysView.vue` 里 480 / 520 / 540px，`ModelListModal.vue` 的 640px，`RouteGroupKeyPicker.vue` 的 960px，一律改成视口内宽度。选择器内部 `76px 72px 88px 150px` 网格在手机上改为纵向或横向滚动，避免挤出屏幕。

7. **状态色**  
   `StatusTag.vue`、`HealthTag.vue`、余额高低色、行高亮 `#ecfdf5` 改到成功绿 / 陶土异常，避免留下旧青绿。

不改后端。本文是计划记录，不改其余设计文档。
